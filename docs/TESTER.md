# Now Mode tester install

This is the Android app for testers. It is not on the Play Store yet. Plans stay on the phone. Uninstalling the app deletes them.

## English

1. Download `nowmode-tester-1.0.1.apk` from the release link you were sent.
2. Open the file. If Android says it cannot install unknown apps, go to Settings → Apps → Special app access → Install unknown apps, choose the browser or Files, and allow it. Then open the APK again.
3. Tap Install, then Open.
4. The first screen asks for an email, a name, and a username. That account stays on this phone. Then a short tour starts. Skip is fine.
5. When Android asks, allow notifications. If it also asks for Alarms & reminders, allow that too. Reminders can then sound while Now Mode is closed.
6. To update, download the newer APK and install it on top of this one. Do not uninstall first. The new file has to be signed with the same tester key, or Android will refuse it.

## Español

1. Descarga `nowmode-tester-1.0.1.apk` desde el enlace que te enviaron.
2. Abre el archivo. Si Android dice que no puede instalar apps desconocidas, entra en Ajustes → Aplicaciones → Acceso especial de apps → Instalar apps desconocidas, elige el navegador o Archivos, y permítelo. Vuelve a abrir el APK.
3. Toca Instalar y luego Abrir.
4. La primera pantalla pide un correo, un nombre y un usuario. Esa cuenta se queda en este teléfono. Después empieza un recorrido corto. Puedes saltarlo.
5. Cuando Android pregunte, permite las notificaciones. Si también pide Alarmas y recordatorios, permítelo. Así los avisos pueden sonar aunque cierres Now Mode.
6. Para actualizar, descarga el APK nuevo e instálalo encima de este. No desinstales antes. El archivo nuevo tiene que estar firmado con la misma clave de prueba, o Android lo rechaza.
